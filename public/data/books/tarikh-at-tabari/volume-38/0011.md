## সূচিপত্র (চলমান)

### ২৮৮ হিজরির ঘটনাবলি (৯০০–৯০১ খ্রিষ্টাব্দ) / ৯৪
- ইবনে আবিল সাজের মৃত্যু / ৯৪
- বাগদাদে বন্দি আমর ইবনুল লাইস / ৯৫
- সামানী শাসকের নিকট প্রেরিত উপহার / ৯৫
- সানআয় বিশৃঙ্খলা / ৯৬
- সাজিদদের গৃহযুদ্ধ / ৯৭
- বাইজেন্টাইনদের সাথে সামরিক সংঘর্ষ / ৯৭

### ২৮৯ হিজরির ঘটনাবলি (৯০১–৯০২ খ্রিষ্টাব্দ) / ৯৯
- কারমাতী নেতা ইবনে আবিল কাওসের মৃত্যুদণ্ড / ৯৯
- আল-মু'তাদিদের ওফাত / ১০১

### আল-মুকতাফী বিল্লাহর খিলাফত
- আমর ইবনুল লাইসের মৃত্যু / ১০৩
- বদরের পতন ও মৃত্যুদণ্ড / ১০৪
- তাবাররিস্তানে সামানীদের বিজয় / ১১২
- জিকরাওয়াইহ ও তাঁর পুত্রগণ / ১১৩

### ২৯০ হিজরির ঘটনাবলি (৯০২–৯০৩ খ্রিষ্টাব্দ) / ১১৮
- সিরিয়ায় নতুন কারমাতী উৎপাত / ১১৮
- সামাররায় রাজধানী স্থানান্তরে আল-মুকতাফীর ব্যর্থ প্রচেষ্টা / ১২০
- ইয়াহিয়া ইবনে জিকরাওয়াইহর মৃত্যু এবং তাঁর ভাই "তিলযুক্ত ব্যক্তি" (হুসাইন) কর্তৃক সিরিয়ায় আক্রমণ / ১২১
- কারমাতী সেনাছাউনিতে এক মাতার পুত্র সন্ধান / ১২৩
- আলেপ্পোর নিকটবর্তী অঞ্চলে কারমাতীদের তৎপরতা / ১২৭
- আল-জান্নাবীর আত্মীয় ও সহচরদের ওপর বাহরাইন থেকে সফল আক্রমণ / ১২৮
- এক সরকারি কর্মকর্তার নিকট "তিলযুক্ত ব্যক্তির" পত্র / ১২৯ এবং তাঁর প্রতি কর্মকর্তার প্রত্যুত্তর / ১৩০
- বাইজেন্টাইনদের সাথে বন্দি মুক্তির আলোচনা / ১৩৩

### ২৯১ হিজরির ঘটনাবলি (৯০৩–৯০৪ খ্রিষ্টাব্দ) / ১৩৪
- আল-মুকতাফী আর-রাক্কাহ নগরীতে / ১৩৪
- "তিলযুক্ত ব্যক্তির" বন্দিদশা / ১৩৫
- কারমাতীদের সাথে মুহাম্মদ ইবনে সুলাইমানের যুদ্ধ / ১৩৬
- কারমাতী নেতৃবৃন্দের মৃত্যুদণ্ড / ১৪১
- আল-কাসিম ইবনে সীমা এবং কারমাতী উলাইসের অবশিষ্টাংশ / ১৪৪, ১৪৭
- হারুন ইবনে খুমারওয়াইহর বিরুদ্ধে অভিযানের প্রস্তুতি / ১৪৬
- তুর্কিদের ওপর সামানীদের বিজয় / ১৪৬
- বাইজেন্টাইন অভিযানসমূহ / ১৪৭
- আল-আব্বাস ইবনুল হাসানের নিয়োগ / ১৪৯

### ২৯২ হিজরির ঘটনাবলি (৯০৪–৯০৫ খ্রিষ্টাব্দ) / ১৫০
- বসরা অঞ্চলের বিদ্রোহীদের দমন / ১৫০
- মারআশের ওপর বাইজেন্টাইন আক্রমণ / ১৫১
- মিসরে মুহাম্মদ ইবনে সুলাইমান, হারুন ইবনে খুমারওয়াইহ নিহত / ১৫১
- মিসরে আল-খালিজীর বিদ্রোহ / ১৫২
