### আল-মু'তাদিদের খিলাফত
- উচ্চপদস্থ কর্মকর্তাদের নিয়োগ / ১
- সাফফারীয় শাসক আমর ইবনুল লাইসের সাথে সম্পর্ক / ২
- রাজকীয় বিবাহের বন্দোবস্তের জন্য বাগদাদে তুলুনীয় দূতাবাস / ২
- রাই নগরীতে দুলাফীদের দ্বারা রাফি' ইবনে হারসামাহর পরাজয় / ৪

### ২৮০ হিজরির ঘটনাবলি (৮৯৩–৮৯৪ খ্রিষ্টাব্দ) / ৬

- ইবনে আবিল সাজ কর্তৃক আল-মারাগাহ বিজয় / ৯
- দুলাফী নেতার মৃত্যু / ৯
- ওমান বিজয় / ১০
- বাইজেন্টাইনদের বিরুদ্ধে অভিযান / ১১
- দাবিল (দ্বীন)-এ ভূমিকম্প / ১২

### ২৮১ হিজরির ঘটনাবলি (৮৯৪–৮৯৫ খ্রিষ্টাব্দ) / ১৩
- তুগজ কর্তৃক বাইজেন্টাইনদের বিরুদ্ধে অভিযানের নেতৃত্ব / ১৪
- আল-জিবাল অঞ্চলে অভিযান / ১৪ এবং হামদান ইবনে হামদুনের বিরুদ্ধে মসুল অভিযান / ১৫

### ২৮২ হিজরির ঘটনাবলি (৮৯৫–৮৯৬ খ্রিষ্টাব্দ) / ১৯
- আল-মু'তাদিদী নববর্ষ প্রবর্তন / ১৯
- আল-মু'তাদিদ ও ক্বাতরুন্নাদার বিবাহ / ১৯, ২২
- হামদানের বিরুদ্ধে অভিযানের ধারাবাহিকতা / ২০
- কাস্পিয়ান যায়দী শাসকের অনুসারীদের জন্য বার্ষিক ভাতা এবং আলীয়দের প্রতি খলিফার মনোভাব সংক্রান্ত আল-মু'তাদিদের স্বপ্ন / ২৪
- খুমারওয়াইহর হত্যাকাণ্ড / ২৬

\* *এই খণ্ডে প্রতি বছরের অধীনে বর্ণিত বিচিত্র ঘটনাবলির কারণে সূচিপত্রে নির্বাচিত বিষয়সমূহের তালিকা প্রদান কিছুটা আবশ্যকীয়ভাবে করা হয়েছে।*
