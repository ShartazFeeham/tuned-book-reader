## সূচিপত্র (চলমান)

### ২৮৩ হিজরির ঘটনাবলি (৮৯৬–৮৯৭ খ্রিষ্টাব্দ) / ২৭
- হুসাইন ইবনে হামদান ও খারেজীদের বিরুদ্ধে অব্যাহত অভিযান / ২৭
- উত্তরাধিকার আইনের সংস্কার / ২৯
- দলত্যাগের পর মিসরীয় কর্মকর্তাদের বাগদাদে আগমন / ৩০
- বাইজেন্টাইন ও স্লাভদের মধ্যকার সম্পর্ক / ৩১
- জাইশ ইবনে খুমারওয়াইহর হত্যাকাণ্ড / ৩১
- বাইজেন্টাইনদের সাথে বন্দি মুক্তির আলোচনা / ৩২
- দুলাফীদের সাথে সম্পর্ক / ৩৪
- আমর ইবনুল লাইস কর্তৃক রাফি' ইবনে হারসামাহর পরাজয় / ৩৯

### ২৮৪ হিজরির ঘটনাবলি (৮৯৭–৮৯৮ খ্রিষ্টাব্দ) / ৪১
- তারসুসে সংঘর্ষ / ৪১
- নবীজীকে (সা.) অবমাননার অভিযোগে খ্রিষ্টান খোজার বিচার / ৪২
- সাধারণ মানুষ কর্তৃক কৃষ্ণাঙ্গ খোজাদের হয়রানি / ৪৫
- উমাইয়াদের বিরুদ্ধে রাজকীয় ফরমান / ৪৬
- প্রাসাদে "ভৌতিক ছায়া"র আবির্ভাব / ৬৫
- বন্দীশালা থেকে দুলাফী আবুল লাইসের পলায়ন এবং পরবর্তীতে মৃত্যু / ৬৭
- বৃষ্টিপাতের ভুল জ্যোতিষতাত্ত্বিক ভবিষ্যদ্বাণী / ৬৯

### ২৮৫ হিজরির ঘটনাবলি (৮৯৮–৮৯৯ খ্রিষ্টাব্দ) / ৭০
- হাজি কাফেলার ওপর আত-তাঈর আক্রমণ / ৭০
- দক্ষিণ মেসোপটেমিয়ায় বায়ুমণ্ডলীয় ধূলিঝড় / ৭১
- বাইজেন্টাইনদের বিরুদ্ধে নৌ-অভিযান / ৭৩
- হারুন ইবনে খুমারওয়াইহর সাথে আলোচনা / ৭৩
- বাইজেন্টাইনদের বিরুদ্ধে স্থল অভিযান / ৭৪

### ২৮৬ হিজরির ঘটনাবলি (৮৯৯–৯০০ খ্রিষ্টাব্দ) / ৭৫
- ইবনে আবিল সাজের সাথে সম্পর্ক / ৭৫
- ইবনে শায়খের বিরুদ্ধে আমিদে সামরিক অভিযান / ৭৫
- হারুন ইবনে খুমারওয়াইহর সাথে চুক্তি / ৭৬
- আমর ইবনুল লাইসের নিকট থেকে প্রাপ্ত উপহার / ৭৭
- আল-জান্নাবীর নেতৃত্বে কারমাতীদের আবির্ভাব / ৭৭
- আল-আনবারের ওপর শায়বানদের আক্রমণ / ৭৮

### ২৮৭ হিজরির ঘটনাবলি (৯০০ খ্রিষ্টাব্দ) / ৮১
- ইবনে শায়খের গ্রেফতার / ৮১
- হাজি কাফেলার ওপর বেদুইন আক্রমণ / ৮১
- বর্ধমান কারমাতী সংকট / ৮২
- তারসুসের বিশৃঙ্খলা / ৮৩
- সামানীদের হাতে আমর ইবনুল লাইসের পরাজয় ও বন্দিদশা / ৮৪
- আল-জান্নাবীর বিরুদ্ধে আল-গানাবীর ব্যর্থ অভিযান / ৮৬
- ইবনে আবিল সাজের মাওলা ওয়াসিফের বিরুদ্ধে অভিযান / ৮৮
- কাস্পিয়ান যায়দী শাসকের মৃত্যু / ৯১
- কারমাতীদের বিরুদ্ধে বদরের সামরিক অভিযান / ৯২
