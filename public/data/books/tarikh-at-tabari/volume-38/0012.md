## সূচিপত্র (চলমান)

- বাইজেন্টাইন ও মুসলিমদের বন্দি মুক্তির আলোচনা / ১৫৩
- বাগদাদে ভয়াবহ বন্যা / ১৫৪
- তারসুসের বিরুদ্ধে বাইজেন্টাইনদের আক্রমণের প্রস্তুতি / ১৫৫

### ২৯৩ হিজরির ঘটনাবলি (৯০৫–৯০৬ খ্রিষ্টাব্দ) / ১৫৬
- আল-খালিজীর বিদ্রোহ / ১৫৬
- সাফফারীয় তাহির ও ফারসের ঘটনাবলি / ১৫৬
- দামেস্কের দিকে কারমাতীদের অভিযান / ১৫৭
- ইয়েমেনের অস্থিরতা / ১৫৭
- কারমাতী আবদুল্লাহ ইবনে সাঈদ এবং বিভিন্ন নগরে (হীত, তাবারিয়া, কুফা) কারমাতী আক্রমণ, সরকারি বাহিনীর পরাজয় / ১৫৮
- জিকরাওয়াইহ / ১৬১
- আস-সাওয়ার প্রান্তরে যুদ্ধ / ১৬৭
- আল-খালিজীর পরাজয় ও বাগদাদে স্থানান্তর / ১৬৯
- কুরুসে বাইজেন্টাইন আক্রমণ / ১৭১

### ২৯৪ হিজরির ঘটনাবলি (৯০৬–৯০৭ খ্রিষ্টাব্দ) / ১৭২
- বাইজেন্টাইন ভূখণ্ডে আক্রমণ / ১৭২
- হাজি কাফেলার ওপর কারমাতী আক্রমণ / ১৭২
- জিকরাওয়াইহর মৃত্যু / ১৭৯
- পেট্রিকিয়ান অ্যান্ড্রোনিকাসের মুসলিম পক্ষে যোগদান, কোনিয়ায় অভিযান / ১৮০
- কারমাতীদের অবশিষ্টাংশের পরাজয় / ১৮১
- বাইজেন্টাইন-মুসলিম বন্দি মুক্তির আলোচনা / ১৮১
- সিরিয়ায় সুফিয়ানীর আবির্ভাব / ১৮১

### ২৯৫ হিজরির ঘটনাবলি (৯০৭–৯০৮ খ্রিষ্টাব্দ) / ১৮৩
- আল-মিসমাঈর বিদ্রোহ / ১৮৩
- সামানী ইসমাইলের মৃত্যু / ১৮৩
- ইয়েমেনের ঘটনাবলি / ১৮৪
- আগলাবী শাসক জিয়াদাতুল্লাহর দূতাবাস / ১৮৪
- বন্দি বিনিময় চুক্তির সমাপ্তি / ১৮৫
- আল-মুকতাফীর ওফাত / ১৮৫

### আল-মুকতাদির বিল্লাহর খিলাফত
- হজের সময় সৈন্যদের দাঙ্গা / ১৮৭

### ২৯৬ হিজরির ঘটনাবলি (৯০৮–৯০৯ খ্রিষ্টাব্দ) / ১৮৯
- ইবনুল মু'তায্যের বিদ্রোহ / ১৮৯
- বাগদাদে হুসাইন ইবনে হামদান / ১৯১

### ২৯৭ হিজরির ঘটনাবলি (৯০৯–৯১০ খ্রিষ্টাব্দ) / ১৯৩
- বাইজেন্টাইনদের বিরুদ্ধে মু'নিস আল-খাদিমের সামরিক অভিযান / ১৯৩, সাফফারীয় আল-লাইসের বিরুদ্ধে লড়াইয়ে ফারস অভিযান / ১৯৩

### ২৯৮ হিজরির ঘটনাবলি (৯১০–৯১১ খ্রিষ্টাব্দ) / ১৯৫
