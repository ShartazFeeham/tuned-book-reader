🏷️ **সূচিপত্র**

১৪১ হিজরীর ঘটনাবলি (৭৫৮–৭৫৯) / ৬২
- রাওয়ান্দিয়্যাদের ঘটনা এবং আবু জাফর আল-মানসুরের তাদের মোকাবিলার পদ্ধতি / ৬২

১৪২ হিজরীর ঘটনাবলি (৭৫৯–৭৬০) / ৭৭
- উয়ায়না ইবনে মুসা ইবনে কা'বের আনুগত্য প্রত্যাহারের কারণ / ৭৭
- ইস্পাহবাদের ঘটনা এবং মুসলিমগণ / ৭৮

১৪৩ হিজরীর ঘটনাবলি (৭৬০–৭৬১) / ৮২
- দাইলামে অভিযান / ৮২

১৪৪ হিজরীর ঘটনাবলি (৭৬১–৭৬২) / ৮৪
- মুহাম্মদ ইবনে খালিদের অনুরোধে যিয়াদ ইবনে উবায়দুল্লাহ আল-হারিছীকে অপসারণের পর আবু জাফরের মুহাম্মদ ইবনে খালিদকে বরখাস্ত করে রিয়াহ ইবনে উসমানকে নিয়োগ দেওয়ার কারণ / ৮৫
- [হাসানের বংশধরদের] ইরাকে স্থানান্তরের কারণ এবং সেই সময়ে তাদের অবস্থা / ১২১
- ১৪৪ হিজরীর অবশিষ্ট ঘটনাবলি / ১৩৮
- [আবু জাফরের] [হাসানের বংশধরদের] ইরাকে স্থানান্তরের কারণ / ১৩৮

১৪৫ হিজরীর ঘটনাবলি (৭৬২–৭৬৩) / ১৪২
- মুহাম্মদ ইবনে আবদুল্লাহর বিদ্রোহ এবং তাঁর শাহাদাত / ১৪২
- এই বছরে মদীনায় কৃষ্ণাঙ্গদের অভ্যুত্থান এবং তার কারণ / ২৩১
- আবু জাফরের বাগদাদ নির্মাণের কারণ / ২৩৭
- ইবরাহীম ইবনে আবদুল্লাহর বিদ্রোহ, শাহাদাত এবং যেভাবে তা ঘটেছিল তার কারণ / ২৫২

উদ্ধৃত রচনাবলির গ্রন্থপঞ্জি / ২৯৩

নির্ঘণ্ট / ৩০৫
