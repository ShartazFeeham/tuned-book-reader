🏷️🏷️ **সূচিপত্র (চলমান)**

**১৯৫ হিজরীর ঘটনাবলি (৮১০–৮১১ খ্রি.)** / ৪৬
আল-আমীন কর্তৃক আল-মামুন ও আল-কাসিমের উত্তরাধিকারী হিসেবে দুআ নিষিদ্ধকরণ / ৪৭
আলী ইবনে ঈসা ইবনে মাহানকে আল-জাবালের সেনাপতিত্ব অর্পণ / ৪৮
আলী ইবনে ঈসা ইবনে মাহানের আল-মামুনের বাহিনীর বিরুদ্ধে লড়াইয়ের জন্য আল-রয়ে যাত্রা / ৪৯
আল-আমীন কর্তৃক তাহিরের বিরুদ্ধে লড়াইয়ের জন্য আবদুর রহমান ইবনে জাবালাহকে প্রেরণ / ৮৪
তাহির ইবনুল হুসাইনের "যু আল-ইয়ামিনায়ন" উপাধি লাভ / ৮৭
সিরিয়ায় আল-সুফিয়ানীর বিদ্রোহ / ৮৮
তাহির কর্তৃক আল-জাবাল প্রদেশ থেকে আল-আমীনের প্রতিনিধিদের বিতাড়ন / ৮৮
আবদুর রহমান ইবনে জাবালাহ আল-আবনাভীর মৃত্যু / ৮৯
বিবিধ তথ্য / ৯১

**১৯৬ হিজরীর ঘটনাবলি (৮১১–৮১২ খ্রি.)** / ৯২
আল-আমীন কর্তৃক আসাদ ইবনে ইয়াযীদকে কারারুদ্ধকরণ এবং তাহিরের বিরুদ্ধে লড়াইয়ের জন্য আহমাদ ইবনে মাযইয়াদকে প্রেরণ / ৯২
আল-মামুন কর্তৃক আল-ফাদল ইবনে সাহলের পদমর্যাদা বৃদ্ধি / ১০১
আবদুল মালিক ইবনে সালিহকে সিরিয়ার গভর্নর নিয়োগ / ১০২
আবদুল মালিক ইবনে সালিহ কর্তৃক আল-আমীনের জন্য সিরিয়ায় সৈন্য সংগ্রহ / ১০৪
বাগদাদে আল-আমীনের বিরুদ্ধে আল-হুসাইন ইবনে আলী ইবনে ঈসা ইবনে মাহানের ব্যর্থ অভ্যুত্থান / ১০৮
মুহাম্মদ ইবনে ইয়াযীদ আল-মুহাল্লাবীর মৃত্যু এবং তাহিরের আহওয়াজে প্রবেশ / ১১৪
তাহির কর্তৃক আল-মাদায়েন দখল এবং সারসারের দিকে অগ্রসর হওয়া / ১২০
মক্কার গভর্নর কর্তৃক আল-আমীনের প্রতি আনুগত্য প্রত্যাহার / ১২৪
হারসামা ইবনে আয়ান কর্তৃক আল-আমীনের বাহিনীকে পরাস্তকরণ / ১২৯
তাহিরের কিছু লোকের আল-আমীনের পক্ষে যোগদান / ১৩০

**১৯৭ হিজরীর ঘটনাবলি (৮১২–৮১৩ খ্রি.)** / ১৩৪
বাগদাদ অবরোধের বিবরণ ও ফলাফল / ১৩৪
কাসর সালিহের যুদ্ধ / ১৫০
তাহির কর্তৃক মাঝিদের বাগদাদে যেকোনো কিছু বহন নিষিদ্ধকরণ / ১৫৬
আল-কুনাসাহ-র যুদ্ধ / ১৫৯
দারব আল-হিজারাহ-র যুদ্ধ / ১৬২
আল-শাম্মাসিয়্যাহ ফটকের যুদ্ধ / ১৬৪
